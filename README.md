# My Custom Quickshell Configuration

This repository contains my **personal Quickshell configuration** based on the amazing work from the [end-4/dots-hyprland](https://github.com/end-4/dots-hyprland) project.

This is my current setup, and I will continue improving and customizing it over time by adding new widgets, features, and personal modifications according to my workflow and preferences.

> ⚠️ This configuration is actively under development. Things may change, break, or be redesigned as new features are added.

---

## ✨ Current Features

Currently, this Quickshell configuration includes the following custom features:

### 1. 🔒 Lock Screen Media Controls

Added media control functionality directly into the lock screen.

Features include:

- Displaying currently playing media information
- Play / Pause controls
- Previous and Next track controls
- Integration with system media players through MPRIS

PR / Source:
- [Lock Screen Media Controls](https://github.com/Nitesh4546/dots-hyprland/blob/lock-screen-media/.github/lock-screen-media.md)

---

### 2. 📱 Application Menu

Added a custom application launcher/menu integrated into Quickshell.

Features include:

- Quick application searching
- Easy application launching
- Quickshell-based UI integration
- Designed to match the overall Material design style

PR / Source:
- [Application Menu](https://github.com/Nitesh4546/dots-hyprland/blob/app-menu/.github/app-menu.md)
